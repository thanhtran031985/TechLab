Module 03 [00:28:56]
Methods, Status Codes & Caching

Nắm vững 10 HTTP Methods, 5 họ mã lỗi, Signed URL upload, 202 Accepted, ETag caching và tính Safe/Idempotent.

So sánh kịch bản Lab
Junior: Dùng POST cho nút Like khiến double-tap nhảy 2 tim; đẩy file nặng qua API server.
Senior: Dùng PUT Idempotent, ETag trả 304 Not Modified và Signed URL tải thẳng lên Storage.
Thử thách (2 / 3)
1. Kiểm chứng Idempotency khi Double-Tap
2. Nhận 304 Not Modified với ETag
3. Upload ảnh lớn qua Signed URL
Khóa học chưa có module nào
Khai báo danh sách module trong content/courses/rest-api/course.json và chạy đồng bộ.
