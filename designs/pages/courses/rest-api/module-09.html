Module 09: Tài liệu & OpenAPI

Video [02:05:09] – [02:11:52]

Design-First & 4 đầu ra từ OpenAPI[02:07:42] – [02:11:05]

  • Một nguồn sự thật: Tài liệu viết tay trên Wiki luôn lệch khỏi code (text vs body). OpenAPI 3.1/3.2 giúp cả người và máy cùng đọc được hợp đồng.
  • Tái sử dụng Schema: Viết mỗi kiểu dữ liệu 1 lần trong components/schemas (dựa trên JSON Schema) rồi trỏ $ref.
  • 4 đầu ra tự động: (1) Interactive Docs UI, (2) Client SDK, (3) Mock Server cho nhóm Mobile chạy song song, (4) Contract Tests kiểm server thực tế.
  • Cổng chặn CI: Dùng oasdiff bắt Breaking Change và Spectral ép đúng style guide trước khi merge.
