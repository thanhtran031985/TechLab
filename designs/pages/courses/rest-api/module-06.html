Module 06: Kiến trúc 3 tầng & Versioning

Video [01:20:30] – [01:40:22]

3 Tầng Server & Chiến lược Versioning[01:20:59] – [01:39:40]

Kỹ thuậtNguyên tắc cốt lõi
3 LayersAPI Layer (HTTP/Status) → Business Layer (Rules thuần) → Data Layer (SQL, Transaction, ẩn tên cột DB).
Tolerant Reader & Expand–ContractĐổi tên trường không cần v2: thêm trường mới song song (text + body) → chuyển app mới → xóa trường cũ khi hết traffic.
4 vị trí đặt VersionPath (/v2), Header (X-API-Version + bắt buộc Vary), Query (?api-version=), Media Type (Accept).
Khai tử API cũKhông tắt đột ngột: trả header Deprecation + Sunset → nhắc cập nhật app → khi traffic ≈ 0 mới trả 410 Gone.
